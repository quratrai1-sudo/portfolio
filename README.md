# Shutter Stories - Photography Portfolio & Booking App

Single-file React architecture par mabni professional photography portfolio application.

## Features

- **Dynamic Gallery & Search:** Images ko categories ke hisaab se filter karein aur titles se search karein.
- **Lightbox View:** Kisi bhi photo par click karke usko full-screen modal me dekhein.
- **Favorites System:** Custom photos ko favorite mark karein.
- **Dynamic Price Calculator:** Booking section me extra hours aur add-ons select karne par live price calculate hoti hai.
- **Dark / Light Mode:** One-click theme toggle.

## How to Run

1. Terminal me packages install karein:
   npm install

2. App start karein:
   npm start
